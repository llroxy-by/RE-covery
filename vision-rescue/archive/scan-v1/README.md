# archive/scan-v1 —— 扫描实验版（未采用主线）

另一条思路的完整实现：**不再逐帧猜，而是在一个信号之后把一次识别做透**。

- 一次扫描抓 8 帧，取最清晰的一帧做主图，其余用来投票
- 多尺度检测（1.0 / 1.5），救远距离的小标签
- 同一块标签跨帧投票，模板与视觉模型互相验证，输出 `high / mid / low` 三档可信度
- 逐块给出「教它」的入口，误读可以当场登记修正

准确率比主线高，代价是**每次 1-2 秒**（还要叫模型），不能连续看。
