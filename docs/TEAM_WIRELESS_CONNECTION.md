# G1 队友无线连接指南

更新：2026-11-07。主办方已确认有线与无线可同时连接调试。队长使用有线；队友可通过 Wi-Fi 登录同一台机器。

## 1. 连接现场 Wi-Fi

电脑连接机器人所在的现场 Wi-Fi。当前机器人屏幕显示：

- HPU 无线 IP：`192.168.167.46`
- 子网掩码：`255.255.254.0`（/23）
- SSH 端口：`22`
- 用户名：`galbot`
- 主机名：`galbot-echo`
- 已核对的 SSH ED25519 指纹：`SHA256:1MH5iIhYyb2gK5Q02SOYqO0Ynil5Xqgh14oqNz/5s6k`

无线 IP 由 DHCP 分配，重启后以机器人屏幕 HPU 的 `wlan0` 地址为准。电脑若是 `192.168.166.x` 或 `192.168.167.x` 且掩码为 /23，可在同一子网。不要将电脑地址设成机器人地址，也不要修改机器人网卡。

## 2. 测试并登录

Windows PowerShell：

```powershell
Test-NetConnection 192.168.167.46 -Port 22
ssh galbot@192.168.167.46
```

macOS / Linux：

```sh
nc -vz 192.168.167.46 22
ssh galbot@192.168.167.46
```

首次连接时核对指纹再接受。密码请向队长或现场人员当面获取；输入时终端不显示字符属于正常行为。不要将密码写入脚本、仓库或日志。

登录后可用以下只读命令确认：

```sh
hostname
ip -brief address
df -h /dev/shm
```

预期主机名 `galbot-echo`。退出用 `exit`。SSH 超时先检查 Wi-Fi、屏幕 IP 和端口；鉴权失败检查用户名与密码，不要重复猜测。

## 3. SDK 环境

机器人已安装 G1 SDK **1.10.0**，无需重新部署。在机器人 SSH 终端中检查导入：

```sh
env PYTHONPATH=/data/galbot/lib LD_LIBRARY_PATH=/data/galbot/lib \
  python3 -B -c 'import galbot_sdk; print(galbot_sdk.__version__)'
```

仅登录、导入 SDK 不会驱动关节。初始化 SDK、读取传感器与运动控制不是同一件事，具体使用前与队长协调；不要为了读一帧数据反复初始化大量客户端。

文档：https://developer.galbot.com/docs/SDK/1.10.0/g1/zh/

## 4. 多人协作约定

- 有线和无线可同时 SSH 登录，并行查看代码、日志及开发资料。
- 同一时刻由一个指定控制者发送关节、底盘、夹爪或使能指令；运动前明确交接。能同时联网不代表运动命令会自动仲裁。
- 队友不要各自启动本仓库 `robot-console/server.py` 来控制同一机器人。队长当前控制台运行在队长电脑 `127.0.0.1:8765`，这个地址在队友电脑上指向队友自己，并非机器人网页。
- 运动测试须有现场看护、清空关节和底盘扫过区域，并保证实体急停可用。
- 不通过 Coding Agent 的 SSH 向机器人写入文件、修改系统配置或部署代码。确需真机改动先联系现场技术人员。不要重装 SDK、重启系统服务或清空 `/dev/shm`。
- 先前发生过共享内存占满，表现为 SDK 初始化失败、关节数据为空。再次出现时记录 `df -h /dev/shm` 结果并联系现场人员，不能直接删除共享内存文件。
