# RE-covery 控制台设计演示版

将本目录完整下载后，把 index.html 拖进浏览器即可离线打开。
Windows 可以双击「启动App.vbs」，通过 Edge 独立窗口打开。

## 演示
生成计划 → 开始模拟复位 → 移开遮挡或取消 → 补全缺失物或跳过 → 丢弃新增物或转移到桌面／货架。
转移时点击桌面空位或货架格位，再确认。
取消、跳过补全或桌面仍有新增物时保持 BLOCKED；满足模拟规则后显示 READY。
刷新或重置会清空本轮记录。导出按钮可下载 JSON。

## 边界
所有观测、动作、耗时、置信度与历史均为模拟，未接入机器人和视觉接口。
机器人动作帧为生成的夹取示意，多个操作使用同一段示意动画，不是真实轨迹或录像。
物品立体预览为 SVG 示意，不是可旋转的真实 3D 模型。
三个素材文件须与 HTML 保持同目录；无网络依赖，无安装步骤。
