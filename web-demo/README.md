# RE-covery 最终设计客户端
Windows：双击「创建客户端快捷方式.vbs」，随后双击带项目图标的「RE-covery 客户端」。
已有本机快捷方式可直接打开。文件夹移动后重新创建快捷方式。
备用方式：双击「启动App.vbs」，或将 index.html 拖入浏览器。

本客户端采用 Edge 独立窗口运行，并非原生 EXE 安装包。
保留模拟复位、人工决策、桌面及货架选点、机器人示意动画、JSON 导出。
真实相机窗口接收 WebSocket 二进制 JPEG，支持冻结 S1；须另行启动相机服务。
真实视觉判断和机器人运动接口尚未接入，模拟 READY 不代表真机验收通过。
所有素材随包提供；图标采用用户提供的原图。
